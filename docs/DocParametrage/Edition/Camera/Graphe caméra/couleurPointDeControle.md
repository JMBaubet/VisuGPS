# 🎨 Paramètre : Couleur Point de Contrôle

Ce document détaille le paramètre `Couleur Point de Contrôle`.

---

## 🎯 Rôle du Paramètre

Ce paramètre définit la couleur des **points de contrôle** (ou keyframes) ajoutés manuellement sur le graphe.

-   **Type**: Couleur
-   **Valeur par défaut**: `purple`

---

## ⚠️ Recommandations

-   Une couleur distincte (comme le violet) permet de repérer immédiatement les endroits où vous avez forcé une valeur manuelle.
