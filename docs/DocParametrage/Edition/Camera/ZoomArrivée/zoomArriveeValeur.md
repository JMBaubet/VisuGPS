# 🔭 Paramètre : Valeur du zoom arrivée

Ce document détaille le paramètre `Valeur du zoom arrivée`, qui définit l'intensité du zoom final.

---

## 🎯 Rôle du Paramètre

Il détermine le niveau de zoom exact atteint par la caméra lorsque la trace touche son point final.

-   **Type**: Entier
-   **Valeur par défaut**: 18
-   **Plage autorisée**: 10 - 22

## 📏 Échelle de Zoom

Les valeurs sont identiques à celles du zoom de départ :
-   **10-12** : Vue large.
-   **13-15** : Vue moyenne.
-   **16-18** : Vue détaillée (recommandé pour voir l'arrivée précise).
-   **19-22** : Vue macro.

---

## ⚠️ Recommandations

-   Une valeur de **18** permet de bien visualiser le "finish" (sommet, bâtiment, parking).
-   Assurez-vous que la cartographie (Satellite ou Mapbox) est de bonne qualité à cet endroit pour ce niveau de zoom.
