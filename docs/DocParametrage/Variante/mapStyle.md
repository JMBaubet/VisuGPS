# 🔢 Paramètre : Style de carte

Ce document détaille le paramètre `mapStyle`, qui permet de choisir le fond de carte utilisé lors de l'édition des variantes.

---

## 🎯 Rôle du Paramètre

Le paramètre `mapStyle` définit l'apparence visuelle de la carte Mapbox affichée dans la vue "Variante".

-   **Libellé**: Style de carte
-   **Type**: Liste de choix
-   **Valeur par défaut**: Standard (Nouveau style Mapbox)

## ⚖️ Valeurs Possibles

| Valeur | Description |
| :--- | :--- |
| **Standard** | Nouveau style par défaut de Mapbox, moderne et performant. |
| **Outdoors** | Style classique pour la randonnée et le vélo, mettant en valeur le relief et les sentiers. |
| **Satellite** | Vue satellite réaliste, utile pour repérer des détails visuels sur le terrain. |
| **Rues (Streets)** | Carte routière classique, claire et lisible pour la navigation urbaine. |
| **Clair (Light)** | Thème gris clair minimaliste, utile pour faire ressortir la trace. |
| **Sombre (Dark)** | Thème sombre, reposant pour les yeux et moderne. |

## 💡 Recommandations

Pour l'édition de variantes, le style **Standard** ou **Outdoors** est généralement le plus adapté car il affiche les détails nécessaires pour tracer des itinéraires précis. Le mode **Satellite** peut être utile en complément.
