# 📏 Paramètre : Affichage Distance (Variante)

Ce document détaille le paramètre `distance`, qui permet de définir si le widget de distance doit être affiché ou masqué lors du lancement de la visualisation d'une variante.

---

## 🎯 Rôle du Paramètre

Le paramètre `distance` contrôle la visibilité initiale du compteur kilométrique affiché à l'écran. Ce widget indique la distance parcourue par rapport à la distance totale de la variante sélectionnée.

-   **Libellé**: Distance
-   **Type**: Booléen
-   **Valeur par défaut**: true (Activé)

## ⚖️ Justification : Pourquoi contrôler l'affichage de la distance ?

L'affichage de la distance est une information clé pour comparer les variantes entre elles.

### 1. 📍 Suivi de la progression

-   Permet de savoir instantanément où l'on se situe sur le tronçon spécifique de la variante.

### 2. 🎥 Immersion visuelle

-   Masquer ce widget permet d'obtenir une vue plus épurée pour se concentrer sur le tracé 3D du nouveau tronçon.

---

## ⚠️ Recommandations

-   **Valeur par défaut (Activé)** : Recommandé pour une utilisation standard afin de fournir des repères à l'utilisateur.
-   **Raccourci clavier** : L'utilisateur peut toujours basculer l'affichage avec la touche **D**.
