# ⛰️ Paramètre : Affichage Altitude (Variante)

Ce document détaille le paramètre `altitude`, qui permet de définir si le graphique du profil d'altitude doit être affiché ou masqué lors du lancement de la visualisation d'une variante.

---

## 🎯 Rôle du Paramètre

Le paramètre `altitude` contrôle la visibilité initiale du profil altimétrique de la variante. Ce graphique montre spécifiquement le relief du tronçon édité.

-   **Libellé**: Altitude
-   **Type**: Booléen
-   **Valeur par défaut**: true (Activé)

## ⚖️ Justification : Pourquoi contrôler l'affichage du profil d'altitude ?

Le profil d'altitude est essentiel pour évaluer la difficulté d'une variante par rapport au tracé original.

### 1. 🚴‍♂️ Analyse de l'effort

-   Permet de visualiser les nouveaux dénivelés apportés par la variante (cols, côtes, descentes).

### 2. 🖼️ Espace écran

-   Masquer ce panneau permet de gagner une surface d'affichage conséquente pour la carte 3D.

---

## ⚠️ Recommandations

-   **Dénivelé** : Indispensable pour les variantes cherchant à modifier le profil altimétrique du parcours.
-   **Raccourci clavier** : L'utilisateur peut basculer l'affichage avec la touche **A**.
