# 🎨 Paramètre : Couleur des Nœuds

Ce document détaille le paramètre `nodeColor`, utilisé dans la configuration des variantes.

---

## 🎯 Rôle du Paramètre

Le paramètre `nodeColor` détermine la couleur des "nœuds" ou points d'ancrage affichés sur la trace maîtresse.

-   **Libellé**: Couleur des nœuds
-   **Type**: Couleur (Material Design)
-   **Valeur par défaut**: `white` (Blanc)

## ⚖️ Justification : Pourquoi ajuster cette couleur ?

Ces points servent de repères visuels pour le "snapping" (accroche magnétique) lors de la création de variantes.

### 1. 📍 Précision

-   **Repérage** : Les nœuds doivent être visibles pour que vous puissiez cliquer précisément dessus afin de démarrer ou terminer une variante sur la trace.
-   **Discrétion** : Ils ne doivent pas masquer la trace elle-même, d'où l'importance de la couleur.

---

## ⚠️ Recommandations

-   **Fond de carte** : Le blanc est généralement très efficace sur les fonds satellite. Sur un fond clair (type "Streets"), une couleur plus sombre pourrait être nécessaire.
