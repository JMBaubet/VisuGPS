# Clé API GraphHopper

## Description
La clé API GraphHopper est nécessaire pour utiliser le service de calcul d'itinéraire (routage) fourni par GraphHopper. Elle permet à l'application de calculer les variantes de vos traces.

## Comment obtenir une clé ?

1.  Rendez-vous sur le site officiel : [GraphHopper Sign Up](https://www.graphhopper.com/dashboard/#/register).
2.  Créez un compte ou connectez-vous.
3.  Une fois dans le tableau de bord (Dashboard), allez dans la section **API Keys**.
4.  Cliquez sur le bouton **Add API Key**.
5.  Donnez un nom à votre clé (ex: "VisuGPS") et validez.
6.  Copiez la chaîne de caractères générée (la clé commence souvent par des chiffres/lettres mélangés).
7.  Collez cette clé dans le champ correspondant dans VisuGPS.

> [!NOTE]
> GraphHopper propose une offre gratuite (Free Tier) suffisante pour une utilisation personnelle standard.
