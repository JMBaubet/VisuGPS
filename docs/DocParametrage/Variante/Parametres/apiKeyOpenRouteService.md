# Clé API OpenRouteService

## Description
La clé API OpenRouteService est requise si vous souhaitez utiliser ce service comme alternative à GraphHopper pour le calcul d'itinéraires. Elle est particulièrement utile pour ses profils VTT et Route.

## Comment obtenir une clé ?

1.  Rendez-vous sur le site officiel : [OpenRouteService Sign Up](https://openrouteservice.org/dev/#/signup).
2.  Créez un compte et validez votre email si nécessaire.
3.  Connectez-vous à votre tableau de bord (Dashboard / Dev Dashboard).
4.  Dans la section **Tokens**, sélectionnez le type de token **Standard**.
5.  Entrez un nom pour votre token (ex: "VisuGPS") et cliquez sur **Create Token**.
6.  Cliquez sur le token créé pour voir la clé complète.
7.  Copiez la clé (une longue suite de caractères alphanumériques).
8.  Collez cette clé dans le champ correspondant dans VisuGPS.

> [!TIP]
> OpenRouteService est gratuit et open-source, avec des limites d'utilisation très généreuses pour les particuliers.
